# The Tower 

> A snappy, momentum-based 2D platformer built in 48 hours for the **GMTK 2025 Game Jam**. 

🎮 **[Play the game on itch.io!](https://stormrun.itch.io/the-tower)**

## 📖 About the Project
*The Tower* challenges players to master momentum and precise timing to climb to the top. This project was developed under a strict game jam deadline, forcing quick problem-solving, efficient scoping, and rapid iteration. 

**My Role:** Lead Programmer and Game Designer  
**Teammate:** [Cloaked](https://cloaked11.itch.io/) (Art and Audio)

## ✨ Key Features & Mechanics
* **Momentum-Based Physics:** Custom-coded player controller that rewards momentum building for longer, higher jumps.
* **Dynamic Tracking Systems:** Built-in dynamic timer and death counter to encourage speedrunning.
* **Custom Visual Effects:** Integrated a custom pixelated dissolve shader (originally by blivi0) to handle player death animations smoothly.
* **Snappy Controls:** Fine-tuned input handling to ensure responsive movement, with quick-reset functionality mapped to the 'R' key.

## 🛠️ Built With
* **Engine:** Godot Engine (v4.6)
* **Language:** GDScript
* **Version Control:** Git & GitHub

## 🚀 How to Run Locally
If you want to pull this repository and run it on your local machine:
1. Clone this repository: `git clone https://github.com/wespd/[Repo-Name].git`
2. Open the **Godot Engine**.
3. Click **Import** and select the `project.godot` file from the cloned folder.
4. Press `F5` to run the project!
